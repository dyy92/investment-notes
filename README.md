# investment-notes

个人投资研究仓库 · 理财经理工作台

用途：集中管理投资相关的研究笔记、自选观察池与组合方案，版本化存档，随时可追溯、可回退。

## 目录结构
- `research/` 研报、个股 / 基金分析笔记
- `watchlist/` 自选股、自选基金观察池
- `portfolio/` 组合方案、配置思路

## 基本用法（日常记录）
1. 在对应目录新建一个 Markdown 文件
2. 暂存并提交：`git add .` → `git commit -m "做了什么"`
3. 推送到 GitHub：`git push`

## 远程仓库
- 地址：`github.com/<你的用户名>/investment-notes`
- 首次推送：`git push -u origin main`

> 说明：本仓库的 Git 作者信息（name / email）目前是占位值，请按下面命令改成你自己的 GitHub 账号信息：
> ```
> git config user.name "你的GitHub用户名"
> git config user.email "你注册GitHub的邮箱"
> ```
> 改完后，之后的提交都会用正确身份；已发生的第一条提交如需修正可忽略，不影响使用。
